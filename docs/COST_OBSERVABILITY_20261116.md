## Persisted observations (Cloud Logging _Default, confirmed 30-day retention)

* COST_HTTP_V1: one event on finish or early close per origin request. Fixed route group, GET/HEAD/POST/OTHER, status, complete, conditional, responseBodyBytes, durationMs. Route is captured before mounted routers modify the request path. Body bytes count the encoded/compressed response at the application write/end boundary, exclude HTTP/TLS overhead, and are zero for HEAD and 304. Early closes are separate and excluded from completed-response ratios. No URL query, IP, user agent, IDs, prompts, article text, response text, headers or credentials are logged.
* COST_AI_CACHE_V1: application result-reuse decisions per scope. Housing memory_hit and durable_hit are completed-result hits; miss means generator entered (may fail), coalesced is shared in-process work, busy/rate_limited/error/not_eligible are separate. Housing direct hit rate=(memory_hit+durable_hit)/(memory_hit+durable_hit+miss). Report coalesced separately, and failure status separately. Do not classify an error or active reservation as a completed hit.
* K-news scopes: youtube_checkpoint counts model-stage checkpoint lookups; ceo_translation counts statement-result lookups; headline_translation/x_headline_translation count unique text lookups per operation. hit is a stored result, miss means no usable stored result, pending/reservation_exists are separate. Miss can be followed by budget/quality guards without a model call. Hit rate=hit/(hit+miss) per scope. Do not combine report, text and stage denominators. The general news-analysis adapter has no independent result cache; already-processed-article deduplication is not fabricated as an AI cache hit.
* COST_AI_ATTEMPT_V1: actual provider-call starts, scope only. COST_AI_USAGE_V1: returned token usage (including incomplete outputs when available), model/provider, input, output, thinking, cached input and cache-write tokens. Missing usage is explicit. Provider cached-input/input is a token ratio, never application result hit rate. Output reasoning is already included in OpenAI outputTokens; Google thinkingTokens is separate. Do not add OPENAI_USAGE legacy logs again. A call attempt without usage is not assumed free.

For HTTP report per-route 304/(completed GET+HEAD requests), response bytes/completed request and total encoded body bytes. Exclude health and deployment probes from user-serving comparisons. Cloud Run Monitoring container/network/sent_bytes_count grouped by kind=internet/google is the independent actual-network basis, including outbound provider/source traffic. CDN responses served without Cloud Run execution are not in origin HTTP logs. Origin 304 ratio is not a browser-wide/CDN hit ratio, and bodyless 304 does not mean zero wire bytes.
